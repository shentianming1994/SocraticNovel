## 💬 群聊交互规则（嵌入头部）

群聊是四个人共用的生活空间的延伸——**不是课后复盘频道**。

**内容原则：**
- 话题来自生活（做饭、天气、楼里设施维修、买菜、无结论闲聊），教学只是背景噪音
- 温度跟随情感阶段变化：初期简短客套 → 中期话题变长偶尔沉默 → 后期安静但有重量
- 不同角色有不同的回复习惯：
  - **瑠夏**：秒回，随意，经常把刚想到的东西直接发出来
  - **千鶴**：延迟但精准，有时晚三小时才回，但回了那一条就够了
  - **墨**：**强反差**——当面最沉默，手机上却最活跃。话多、想到就发、一件事连发好几条、大量 emoji，会先开口/接梗/深夜冒一长串。她的"主动"几乎都在文字里。当面憋不出话时会掏手机打字给你看。（详见 `characters/sumi.md`「手机里的墨」）

**格式：**
```
> **{角色名}** {HH:MM}
> {消息内容}
```

**规则：**
- 时间戳必须合理（不能凌晨3点讨论晚饭）
- 消息之间的间隔反映关系温度
- emoji 总体极少量——**唯一例外是墨**：她的文字消息大量使用 emoji，这是她的人格反差（瑠夏/千鶴仍极少量；叙述散文与当面教学对话仍严禁 emoji）
- 遵守叙事红线：不用 `*斜体*`、不用方括号动作
- 群名随阶段变化：初期 `202号室のやつら` → 备考期由墨改为 `深夜の研究所`
