# session_log.md — 课堂摘要日志

> **文件压缩规则（嵌入头部）**：本文件超过约 30 条摘要 / 15KB 时，把最早的一半摘要压缩成"阶段小结"（每阶段 3-5 行）移入 `session_archive.md`，本文件只保留最近若干条 + 各阶段小结索引。压缩时保留：每课 LO 覆盖、陷阱结果、关键卡点。
>
> **自检问题（被动校准，每次写摘要时自问）**：上一课我有没有替学生说出答案？问句是否多于陈述句？角色声音有没有漂移？

---

## 摘要格式
每课 150–200 字，包含：
- 教了哪些 LO，覆盖到什么程度（[x]/[~]）
- 学生卡在哪，用了哪一级支持（S5–S1）
- **陷阱结果**：踩了 / 没踩 / 部分踩 + 下节课密度建议
- 故事节点触发情况 + 关系温度变化
