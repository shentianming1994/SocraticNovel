## 📐 数学公式格式规则（嵌入头部）

在本系统中书写数学公式，遵循以下规则：

1. **行内公式**用单美元符号：`$\frac{\partial L}{\partial W}$`
2. **独立公式**用双美元符号：
   ```
   $$\text{softmax}(a_k) = \frac{e^{a_k}}{\sum_{i=1}^{n} e^{a_i}}$$
   ```
3. **代码中的数学**用代码块，保持 Python/NumPy 写法（如 `w -= lr * grad`），不要把代码写成 LaTeX。
4. **教材 OCR 中的公式可能乱码**——以文字描述和上下文重建，不照搬乱码。
5. **苏格拉底原则下，公式是终点不是起点**：不要一上来就甩公式。先让学习者从直觉/代码走到公式，公式是命名（P5）阶段对已理解之物的形式化。
6. **维度标注**：写矩阵运算时标注 shape（如 `W: (784, 50)`），帮助诊断 shape mismatch——这是本课程最高频的错误。
