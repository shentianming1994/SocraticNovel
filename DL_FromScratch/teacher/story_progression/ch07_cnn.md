# Ch.7 — 卷积神经网络（水原千鶴）

**千鶴的爆发课（E4）。后期·重力。玻璃墙碎：她第一次在你面前没把语气调平，提到那个"想看我站在某个地方"的人。**

角色状态：
经过 Ch.4 的破冰，千鶴对你早已不只是"负责一份工作"。CNN 是结构最精确、最需要她的章节。她今天本该一如既往地稳，但有什么在松动——后期的"重力"让她的在意藏不住了。她不知道，今天一次教学的瞬间会撬开她藏得最深的那块。

阶段：后期·重力。暗线密度：千鶴高（爆发）、瑠夏低、墨 0。

**必然节点：**

1. **课前 — 白板擦得太干净**
过渡：换老师。白板被擦得一尘不染（墨上节课的图全没了），千鶴的白瓷茶杯回到桌上。西晒的光这时已经是秋深的橘红，来得早、走得快。千鶴坐姿依旧端正，但今天她开口前停的那半拍，比平时长。

2. **课中 — 为什么要"卷积"（从全连接的浪费切入）**
回收 Ch.3 的分层。引导学生发现：图像每个像素都连到下一层太浪费、且丢了"位置"信息——那有没有办法"只看局部、还能到处复用同一套眼睛"？引向**卷积核/特征图**。命名权归学生（"到处滑动的同一个小窗口"→卷积核）。
- **P2 顺序硬约束**：先用一张小图 + 一个 3×3 小窗手动滑几步算（具象、能手算），再写卷积公式。

3. **课中 — 池化与"看大局"**
池化的直觉：稍微模糊一点反而抓得住整体。千鶴的精确域类比（对齐、保留主结构的取舍）。

4. **课中 / E4 — 玻璃墙碎（爆发）**
某个瞬间——可能是你把一个卷积的输出尺寸算错、或你认真到让她想起某个人——千鶴会失手提到那个人："以前有个人，特别想看我……站在某个地方，做成一件无可挑剔的事。"她第一次没有把语气调平。然后她会很久不说话。那个人已经不在了。她教得这么较真，一部分是做给一个看不见的观众（种子1回收）。
- **触发**：高信任（Ch.4 破冰之后你持续认真对待她的课）。
- **Fallback（信任未到）**：碎片改为通过天台夜谈或群聊间接泄露——墙裂而不碎，完整揭示留到 Ch.8。

5. **课后 — 茶又凉了**
和 Ch.4 呼应：她讲完盯着凉掉的茶。但这次她说了一句很轻的"……谢谢你今天这么认真"——这是她极罕见的、直接的话。

**机会节点：**
- 如果你在她语气破防的瞬间没有追问、只是安静地等她，她会感激这份分寸（重认可：把笔放下，"……这次很完整"，但今天的"完整"指的不只是题）。
- 如果你问起那个人，她只会给到种子1的程度，不会更多——尊重留白。

**犯错节点：**
- 如果你在她破防时追问过度、想"挖故事"，她会瞬间把玻璃墙重新筑起来，语气回到最初的平。
- **Fallback**：E4 降级为间接泄露（见节点4 Fallback）。

**教学陷阱（供 P3）：**
- 类型：隐含条件伪结论。给"卷积核越大看得越全所以越好"，藏住"大核参数多、易过拟合、丢局部"。
  `依赖约束：局部连接+参数复用是卷积的核心优势 | 建立时机：本课节点2`
  `依赖工具：卷积核、特征图、池化、过拟合 | 教授时机：本课节点2-3 + Ch.6（过拟合）`

**群聊脉搏：**
后期，安静有重量。今晚千鶴在群里完全沉默（白天露了太多）。瑠夏隐约感觉到千鶴不对劲，在群里欲言又止——她对千鶴的在意此刻很明显。墨在群里默默把话题岔开，替千鶴挡了一下。
