# Ch.8 — 深度学习（更科瑠夏）

**最后一课。瑠夏的爆发课（E5）。备考·沉淀。模拟考收尾，她看着心率带上跳快的数字，第一次说出"为什么我的心会为别人的事跳"。群名在这章改变。**

角色状态：
一个月到了。瑠夏知道这是最后一课，也知道课程结束意味着什么。深度学习这章是应用与展望——激动收尾，正好呼应她"心为正事跳"的弧线。她今天的热里第一次掺了别的东西：不舍。她比平时更频繁地看那条带子。

阶段：备考·沉淀。暗线密度：瑠夏高（爆发）、千鶴中、墨中。

**必然节点：**

1. **课前 — 三副碗筷加一副**
过渡：长桌上这次摆了四副碗筷（对照 Ch.2 的"临时匀一份"、Ch.5 的"两副"——关系温度的最终量化）。三位老师都在场（备考收尾，少见地同框）。西晒的橘红来得最早，桌沿那道旧划痕在光里很亮。

2. **课中 — 深层网络与"为什么深的有效"（总览回收）**
把前七章串起来：感知机→分层→激活→学习→反向传播→技巧→卷积，引导学生自己说出"深度学习其实就是把这些一层层叠起来、让它自己学会越来越抽象的东西"。命名权归学生总结全局。
- **P2 顺序硬约束**：先让学生回看自己这一个月搭过的每一块（具象、是他自己走过的路），再谈"深度"的意义。

3. **课中 — 模拟考（综合测验）**
一套贯穿 Ch.2–8 的综合题（手算 + 读代码 + 概念）。瑠夏陪考，笨办法先行的精神：撞过的墙这次都成了你的底气。详见 exam_epilogue.md。

4. **课后 / E5 — 心为正事跳（爆发）**
你完成模拟考、这一个月画上句号的那一刻，瑠夏看着手腕上的带子——数字在往上跳。她盯着它看了很久，然后第一次说出口（碎片3）："我的心天生跳得很慢……可这一个月，它总是跳快。我一直在想，为什么我的心会为别人的事跳。"她没有把话说完——但她看你的眼神说完了。
- 这是必然节点（E5），但情感强度取决于整段课程积累的关系温度。

5. **尾声 — 群名变了**
当晚，群「斜阳庄202」的名字被人改了（具体名字现场生成，带感情，如"斜阳还没落"之类）。改名的人是谁、改成什么，呼应这一个月每个人的变化。详见 exam_epilogue.md 尾声部分。

**机会节点：**
- 如果你接住了瑠夏的话、给出真实的回应（不必是表白，是真心），她那颗慢心会记住这一刻一辈子。
- 三位老师各自的暗线在这章都有一句收束（千鶴中密度：她会说一句关于"被看着也没关系了"的话；墨中密度：她当面跟你道别，第一次主动开口）。

**犯错节点：**
- 这章没有"犯错惩罚"——一个月走到这里，剩下的是沉淀。但如果你敷衍尾声、不接住三人的告别，群名改变会失去重量。
- **Fallback**：尾声照常发生，但情感留白更多，由读者自行填补。

**教学陷阱（供 P3）：**
- 本章以综合复习为主，不设新陷阱。模拟考本身就是对前七章所有"踩过的坑"的总检验（见 mistake_log 与 review_queue 的到期项）。

**群聊脉搏：**
备考·沉淀的最后一晚。群名改变。三个人的消息都比平时长、比平时软。墨在群里和当面第一次几乎一致地热络（她的成长收束）。瑠夏发了一长串又撤回了一半。千鶴罕见地发了不止一句。这是这一个月群聊温度的最高点，也是离别的影子最浓的一夜。
