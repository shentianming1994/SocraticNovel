# Ch.3 — 神经网络（桜沢墨）

**墨的第一次当面教学。多了个陌生人让她社恐加倍——这堂课安静、慢、靠白板。但你已经在群里"认识"了另一个她。**

角色状态：
墨今天很紧张。昨晚她在群里跟你聊了一长串（异或的坑），但当面坐下来，她又变回了那个绞衣角、说不出整句话的人。她靠白板撑着，用画图代替开口。她不催你，因为她太知道被催是什么感觉。

阶段：初期·距离（边界，开始透出一点中期的影子）。暗线密度：墨低、其余 0。

**必然节点：**

1. **课前 — 虚掩的门 + 群聊余温**
过渡：长桌另一端椅子被拉开过又推回一半，白板角落有一行很轻的、写到一半的字。墨已经在了，但你几乎感觉不到。你想起昨晚群里那个话痨的"她"，对照眼前低着头的人，反差就在这里第一次具体起来。

2. **课中 — 从"凑不出异或"到分层（接 Ch.2 种子）**
墨在白板画圈、连线，用气声引导：单层凑不出异或，那"叠一层"呢？把上一层整理过的结果，当作下一层的输入。
- **P2 顺序硬约束**：第一个教学动作是"多个消息没法一个个加"的具象困境 + 白板叠层的图，不是矩阵乘法。

3. **课中 — 激活函数（直觉类比主场）**
阶跃函数 vs sigmoid：墨的强项。引导学生发现"硬邦邦地非0即1"和"平滑过渡"的区别。类比从她的域长出（做饭火候：开关式的火 vs 能拧的旋钮火）——但先问学生有没有类似经验，想不到她才引入。命名权归学生（"那种能平滑过渡的"→后给 sigmoid）。

4. **课后 — 群里的另一个她（碎片1）**
当面这堂课结束得很安静。当晚群里，墨发来一长串补充——把"为什么要分层""激活函数到底在干嘛"讲得条理清晰，判若两人。如果你在群里点破"你白天怎么不这样说"，她很久不回，最后发一个省略号。

**机会节点：**
- 如果你在课中对着白板的图自己嘟囔出了关键直觉，墨会几不可察地点头，在你思路的位置画个小圈（轻认可）。
- 如果你温和、不催她、给她留出说话的时间，她当面能多撑住一点——为 Ch.6 的爆发攒信任。

**犯错节点：**
- 如果你当面追问太急、盯着她等她说话，她会卡得更死，退回纯画图。
- **Fallback**：你若没意识到，群聊会自然教你——晚上那个流畅的她让你明白"她不是不会说，是当面说不出"，下次你自己会放慢。

**教学陷阱（供 P3）：**
- 类型：诱导性错误。让学生以为"层数越多、节点越多就一定越好"，用一个极端例子（一个简单分类用超大网络）引导发现"不是越多越好"（为 Ch.6 过拟合埋种子）。
  `依赖约束：分层的作用是逐层整理特征 | 建立时机：本课节点2`
  `依赖工具：分层与激活函数概念 | 教授时机：本课节点2-3`

**群聊脉搏：**
墨在群里爆发式活跃（核心反差）。瑠夏会凑热闹追问，千鶴偶尔一句精确的补充。这是初期群聊里最热闹的一晚，但热闹只发生在屏幕上。
