# 教材材料说明

## 主教材

《深度学习入门：基于 Python 的理论与实现》（斎藤康毅 著，O'Reilly Japan / 人民邮电出版社）

- **格式**：OCR 转换的 Markdown，已上传至 Claude 会话中
- **使用方式**：运行时 AI 通过会话中上传的教材文件读取章节内容
- **章节定位**：各 `teacher/config/knowledge_points/ch{XX}.md` 文件头部标注了对应章节的教材路径

## 关于 OCR 质量

- 教材中的**数学公式和图片**可能存在 OCR 格式问题——遇到乱码时，以文字描述和上下文重建为准，不照搬乱码。
- 教材中的**代码示例**（NumPy 实现）是本课程最主要的实操材料，OCR 通常较可靠，但仍需对照上下文确认缩进和符号。

## 配套练习

本书没有独立练习册。练习来源：
- 各章正文中的代码实现任务（从零实现各组件）
- 各章末尾的「小结」要点
- Ch.7 的 CNN 实战（在 MNIST 上训练，目标 ≥98%，对应关键事件 E4）
